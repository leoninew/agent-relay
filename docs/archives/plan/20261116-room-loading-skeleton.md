## Technical decisions / 技术设计与决策

- 新增轻量 `AppSkeleton.vue` 与 `RoomLoadingSkeleton.vue`。聊天室骨架通过现有 `RoomWorkbench` 插槽装配，沿用分栏、折叠偏好和响应式断点；不复制一套布局。
- T01 仅在无 snapshot 且正在加载时显示整体骨架。输入区使用装饰占位；有 snapshot 后继续使用原工作台、编辑器和加载逻辑，细分状态由 T02 负责。
- 骨架本体不可交互、不进入读屏；外部提供统一加载提示与忙碌语义。T01 使用静态占位和主题变量，短请求延迟及动效细化属于 T03。
- 切换房间时立即设置加载状态并取消旧查询，对频道列表异步结果使用现有查询版本保护；避免空状态闪现、旧错误覆盖新目标及等待频道列表期间目标变化失效。
- 不修改接口、消息发送、频道缓存策略或后端服务管理。
- T02 通过房间／频道及话题、成员、关键词识别消息查询归属；同查询刷新保留消息与滚动，新查询只显示消息区骨架，同频道编辑器保持就绪。
- T03 将骨架块显示延迟 150ms，加载语义立即生效；查询变化、加载结束、页面暂停及释放清理计时器，真实内容立即呈现。脉冲仅在允许动态效果时启用，消息、导航、搜索和输入区占位复用现有尺寸规则。
