## 技术选择与影响范围

采用独立 `help/` 包和锁文件，沿用 `.node-version`（22.23.4）与 pnpm 10.34.9。VitePress 可直接用 Markdown 生成静态文章、导航和本地预览；相比引入 Jekyll 的 Ruby 工具链更贴近项目。相比复用应用 Vue Router，不需要运行后端或为 Pages 配重写。代价是多一份依赖锁；实施时选择兼容的稳定版并冻结安装。帮助站不进入桌面包、不依赖本机数据库、不新增 API。

仅以 `help/content/` 为内容根，显式列出文章与静态资源，目标根 `https://leoninew.github.io/conflua/`，文章保留静态 `.html` 路径。首版中文，应用入口随现有语言切换，不承诺英文手册。平台指南迁入内容根，旧路径保留短指引以兼容 README、发布指南及历史入链；不复制安装正文。仓库本身公开，发布边界指站点产物，不意味着仓库文件保密。
