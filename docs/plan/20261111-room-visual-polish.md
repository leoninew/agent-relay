## Technical decisions / 技术设计与决策

- 颜色使用白色 `#FFFFFF`、浅灰蓝 `#F5F7FA`、深色文字 `#0F172A`、蓝色 `#2563EB` 与辅助色 `#64748B`；浅色 destructive 改为约 `#DC2626`，提高小字错误提示对比度。
- 正文 14px、辅助和详情内容 12px、弹窗标题 16px，各自配对行高；补充明确的系统中文字体回退，不增加远程字体依赖。工作台分区标题保持 14px。
- 按用户最新要求移除 ring、焦点光晕及高亮描边；输入使用中性色边框反馈，键盘按钮保留低调的中性色虚线提示，错误色优先。搜索容器与按钮使用胶囊形，按钮显式使用 AppButton primary 原语。
- 项目菜单在 `(hover: none)` 或 `(pointer: coarse)` 下常显并扩大点击区域；桌面悬停交互继续沿用。
- 手机布局为“项目栏 → 可折叠导航 → 消息 → 输入”；用 Reka Collapsible 包装 sidebar slot，默认折叠，展开区高度有上限；主区域使用 flex 和 `100dvh`，移除手机固定 680px 高度。
- 长消息最大宽度使用 `min(88%, 88ch)`，手机仍为 92%；消息左右对齐和详情选择语义不变。
- 桌面整体样式按用户最新要求改为连续白色工作区，取消三栏及折叠栏的独立底色、外框与圆角；以现有分隔线、分组间距和输入容器区分导航、阅读与编辑，保持蓝色品牌与选中态、既定字号和面板恢复宽度。
- 话题与成员为同级独立面板，在共同导航容器内并列渲染；移除 TopicSidebar 承载成员的 slot，两者使用相同的 RoomSidebarSection 标题栏、56px 高度、间距与分隔线。
