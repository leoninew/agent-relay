## Technical decisions / 局部技术设计

- 本功能按需要提供目录、单条/话题分页/关键词查询，参数和返回随该功能落实；查询源是 Relay 已持久消息，不扫描 Codex 普通输出。
- 话题查询仅限当前成员订阅；按 ID 查询必须是实际接收人或消息至少命中一个订阅话题。引用本身不授予读取权限，跨房间请求拒绝。
- Offset 唯一键为 memberId/topicId。按话题查询只推进该话题；按 ID 查询只推进该消息关联且成员已订阅的话题；更新为 max(old, returnedSeq)。
- 空结果、失败、无订阅交集的直接 @ 不推进；成功查询仅记录本次由服务提供的消息，不声称模型已读或理解。回查不降低位置，跳读不补齐空洞。
- 查阅记录保存本次成功返回的消息 ID/话题/Seq，按已有 max 规则推进位置；不等待宿主 completed/success，不设后台工具核对，不重跑查询补出其他结果。
- room_catalog 返回轻量话题/成员稳定 ID，供模型填写结构化目标；管理写权限另依 D10，不因目录读取自动授予。
- 返回“查阅位置后新增数”只按话题消息统计，不标“精确未读”。位置不参与路由、队列领取、重试或历史范围校验。
- 话题创建/订阅写操作按 D10 独立授权，不因具备查阅工具就附带成员管理能力。

## Implementation outline / 实施安排

1. 在统一身份上下文实现三类有界读取及权限校验，接入实际工具协议。
2. 增加 Offset 迁移和单调更新，按服务本次成功返回写查阅位置；可选记录返回的实际消息 ID。
3. 为轻量 Prompt 与 Web 提供位置/位置后数量接口，不批量注入历史正文。
4. 完成跳读、回查、跨话题、直接 @ 与失败路径证据，更新成员工具说明。

## Checks and risks / 检查与风险

- 成员不能读未订阅话题全部历史；被直接 @ 可读该条但不能读同话题其他无权消息；引用不可越权。
- 话题分页/关键词限制、Seq 跨页、跳过旧消息后回查、并发 max 更新、空结果与工具返回失败覆盖。
- 重复查阅、空结果、失败与回查只影响对应记录，不触发任何 Message/Delivery 创建或新队列提交。
- 相关 pytest、mypy、ruff；工具传输若不能证明远端收取，文案仅记录服务可证实的返回边界，不升级为已读回执。
