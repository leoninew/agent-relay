# 意图：聊天室与频道的新消息提醒
最后修改时间: 2026-11-18 17:25:05

审查状态：Accepted。用户在评估 #533、#534 后要求「记录后实施」，暂无需要用户确认的未决事项。

## 目标与验收
- A01：当前房间的非当前频道（含默认频道）有他人新消息，在名称右侧显示契合主题色的小黄点；其他房间按频道聚合为一个小黄点。当前导航项不重复提示。
- A02：首次使用以现状为基线；重开浏览器保留查看位置。只提示未删除消息，不按投递、成员活动、本人发言或话题查阅记录判断。
- A03：切换路由本身不算查看。只有在前台成功展示相应频道时间线时推进该频道位置，失败、后台、访问兄弟频道不代为清除。
- A04：保留名称截断、菜单、排序和键盘操作，读屏用户也能获得提醒。

## 边界与工作量
用户需要找到有新对话的位置，不是逐条确认阅读。无精确计数、桌面通知或跨设备已读同步。工作量中等：一条只读摘要贯穿数据库、前端状态与两处导航；复杂度主要是首次基线和异步页面切换，风险是误清。按单任务实施，共享同一接口与验收，无独立子任务。
