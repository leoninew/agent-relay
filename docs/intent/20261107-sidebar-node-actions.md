# Intent / 意图：话题和成员节点操作
最后修改时间: 2026-11-07 20:10:13

Accepted。用户要求话题和成员节点悬停展示“编辑”“删除”文字，点击动作打开模态窗完成功能；常规点击仅过滤消息。沿用当前聊天室、统一组件和反馈，不涉及其他后端任务。

验收：话题点击过滤对应话题；成员点击按发言人过滤当前消息，重复点击取消成员筛选，“全部消息”清除筛选。编辑和删除动作独立，不触发筛选。编辑窗回填并保存现有字段；删除窗展示对象与影响，确认后执行。删除后不再显示为可用节点或路由目标，原消息和投递记录保留，成员原 Codex 会话不受影响。

沿用用户约束：不新增反向测试，不为迁移功能编写单元测试或替代集成测试。
