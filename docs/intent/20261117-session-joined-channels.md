# Intent：添加成员时展示会话已加入的频道
最后修改时间: 2026-11-17 20:32:41

## 审查状态与授权

Accepted。依据用户要求，在添加成员模态窗的会话上展示已加入频道；本次推进实施和必要开发检查，不提交 Git。

## 背景、目标与边界

- 同一个 Codex 会话允许加入当前聊天室的多个频道，目前候选会话仅携带当前频道的成员 ID，无法展示其他频道归属。
- 在可加入会话卡片上展示当前聊天室内已加入的活跃频道名称；未加入任何活跃频道时明确显示空状态。不可用会话不展示频道归属，会话列表不展示会话 ID。
- 不改变会话发现目录、可用性、当前频道去重、成员创建及跨频道加入规则，不展示其他聊天室或已归档、已删除频道的历史归属。

## 场景与验收

- A01：一个会话加入多个活跃频道时，候选接口返回各频道 ID 和名称；未加入时返回空列表。
- A02：可加入会话展示已加入频道，多个频道可换行，支持中英文文案；不可用会话不展示频道归属。
- A03：其他频道的成员关系不阻止加入当前频道；当前频道已加入会话继续由现有规则过滤。
- A04：已移除成员、非活跃频道及其他聊天室不计入结果。
- A05：添加成员的可加入和不可用会话均不显示会话 ID，选择和提交仍使用原会话 ID。

## 工作量、决策与风险

- 小型前后端变更，扩展现有候选 DTO 与批量读取即可，无数据库迁移，不拆分 task，无未决产品问题。
- 频道范围沿用当前频道列表的活跃定义；成员关系来自持久化数据，不从前端缓存或会话状态推断。
- 主要风险为跨聊天室泄漏及将其他频道关系误当成当前频道重复加入，分别由查询范围测试与应用/API 契约测试覆盖。
